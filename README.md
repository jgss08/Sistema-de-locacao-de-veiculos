# Sistema de Locadora de Veículos

Sistema de gerenciamento de uma locadora de veículos desenvolvido em Java.

## Funcionalidades

- Cadastro, alteração, exclusão, listagem e busca de clientes.
- Cadastro, alteração, exclusão, listagem e busca de veículos.
- Gerenciamento de motos, carros e caminhões.
- Realização, alteração e exclusão de locações.
- Devolução de veículos e cálculo do valor total.
- Listagem de clientes e veículos em ordem alfabética ou por placa.
- Validação de dados e prevenção de cadastros duplicados.
- Armazenamento de dados em memória.

## Estrutura do Projeto

- **Programa:** inicialização do sistema e cadastro de dados iniciais.
- **menus:** interação com o usuário, dividida em MenuPrincipal, MenuClientes, MenuVeiculos e MenuLocacoes.
- **entidades:** representação dos objetos e suas características.
- **servicos:** gerenciamento das operações e regras de negócio da locadora.
- **repositorio:** armazenamento e gerenciamento dos dados.
